# src/ui

Phase 6 provides native settings and profile windows, plus a list editor for
global/profile inclusions and exclusions. The list editor adds and removes item
IDs and displays up to twelve at a time; `/djw lists` supports bulk import/export.
Poor-quality toggle and item previews remain read-only. Profile deletion/reset
remain chat-only. The custom rule editor and optional bag adapters remain future
work; new native-frame behavior needs original-client review.
