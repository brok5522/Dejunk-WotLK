# فاز ۶: آغاز رابط تنظیمات

> این سند وضعیت قدیمیِ UI ساخته‌شده برای پورت را شرح می‌دهد. هدف نهایی، تطبیق
> صفحه‌ها و تعامل‌های Dejunk اصلی با APIهای WoW 3.3.5a است؛ این UI آزمایشی
> پذیرش نهایی محسوب نمی‌شود.

نسخهٔ فعلی یک پنجرهٔ آزمایشی `/djw config` دارد؛ این رابط، پنجرهٔ اصلی Dejunk نیست و نباید به‌عنوان پورت UI تحویل یا منتشر شود. فیلترها و داده‌ها باید با رفتار ذخیره‌سازی و صفحه‌های نسخهٔ مرجع بازسازی شوند. ویرایشگر ALL/ANY هم خارج از Dejunk اصلی است و از منطق تصمیم‌گیری حذف شده است.

پیش‌نمایش SELL و DESTROY در پنجرهٔ جدا، تصمیم هر جای کیف، دلیل و شمار کل را نشان می‌دهد؛ این گزارش فقط‌خواندنی است. پنجره هیچ دکمه‌ای برای فروش، تعمیر یا
حذف واقعی ندارد. سرویس‌های فروش، تعمیر و حذف همچنان به بازی وصل نیستند.

این فاز هنوز تکمیل نشده است؛ رابط اصلی، کنترل‌های فروشنده، آیکن کیف، نقشهٔ کوچک
و تعامل‌های کلاینت ۳٫۳٫۵ باید از نسخهٔ مرجع پورت و داخل بازی بررسی شوند.
