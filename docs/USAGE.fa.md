# وضعیت فعلی Dejunk برای WoW 3.3.5a

## نتیجهٔ کوتاه

پورت هنوز کامل و آمادهٔ انتشار نیست. هدف پروژه فقط سازگارکردن خود Dejunk اصلی
با WoW 3.3.5a، بیلد 12340، Interface 30300 و Lua 5.1 است؛ رابط یا قابلیت تازه
هدف نیست. رابط فعلی چند پنل آزمایشی دارد و هنوز UI اصلی Dejunk نیست.

## چه چیزهایی انجام شده

- سازگارسازهای API قدیمی، کنترل بیلد، خواندن کیف و باطل‌کردن کش پیاده‌سازی
  شده‌اند؛ در نبود دادهٔ مطمئن، نتیجه نامشخص می‌ماند.
- ذخیره‌سازی پروفایل‌ها، فهرست‌ها و بخشی از تنظیمات/طبقه‌بندی با آزمون‌های
  رگرسیون آفلاین پوشش داده شده است.
- فرمان‌های بررسی کیف و پیش‌نمایش SELL/DESTROY فقط گزارش می‌دهند و هیچ عملی
  روی آیتم انجام نمی‌دهند.
- موتورهای فروش، تعمیر و حذف فقط با آداپتور ساختگی آزموده شده‌اند و به APIهای
  واقعی بازی متصل نیستند.
- ZIP توسعه‌ای به‌طور تکرارپذیر ساخته و بررسی می‌شود؛ این کار آن را به نسخهٔ
  قابل انتشار تبدیل نمی‌کند.

## چه چیزهایی مانده

1. انتقال پنجرهٔ اصلی، فهرست‌ها، تنظیمات سراسری و پروفایل، کلیدها و پنجره‌های
   انتقال داده از UI نسخهٔ مرجع، بدون طراحی دوباره.
2. انتقال نمایش آیتم و اتصال‌های کیف، تاجر، نقشهٔ کوچک، آیتم‌های دورریختنی و
   قابل غارت.
3. تکمیل رفتار اصلی فروش/تعمیر و حذف تک‌آیتمی مطابق نسخهٔ مرجع؛ فعلاً هیچ‌کدام
   در بازی اجرا نمی‌شوند.
4. بررسی فقط‌خواندنی پنجره‌ها و ورودی‌ها در کلاینت اصلی بیلد 12340.
5. بازبینی ایمنی و مجوز جداگانه پیش از اتصال یا آزمودن هر عملیات تغییردهندهٔ
   کیف.
6. اجرای دوبارهٔ همهٔ آزمون‌ها، بررسی مهاجرت داده و مجوزها و سپس آماده‌سازی
   نامزد انتشار.

## نتیجهٔ آخرین بررسی آفلاین

در تاریخ 2026-11-12، `tools/check.py` با مفسر واقعی Lua 5.1 اجرا شد: 57 آزمون
رفتاری بدون شکست، 18 آزمون ذخیره‌سازی، 8 آزمون سرویس، 11 آزمون تخریب، 62 آزمون
مدل UI و آزمون مسیرهای تعاملی UI موفق شدند. نحو 24 فایل Lua، مرز فقط‌خواندنی،
ساخت بستهٔ ZIP تکرارپذیر و `git diff --check` نیز موفق بودند.

این نتایج جای تست در خود بازی را نمی‌گیرند. UI و شروع افزونه در کلاینت اصلی برای
نسخهٔ فعلی **آزمایش نشده‌اند**. اسکرین‌شات‌ها و گزارش‌های قبلی مربوط به نسخه‌های
قدیمی‌تر هستند و تأیید این نسخه محسوب نمی‌شوند.

## چه زمانی از شما تست کلاینت می‌خواهم؟

بعد از اینکه پنجره‌ها و تعامل‌های نسخهٔ مرجع در کد منتقل و چک‌های آفلاین سبز
شدند، یک بستهٔ مشخص برای تست فقط‌خواندنی می‌دهم و دقیقاً می‌گویم چه فرمان‌هایی
را اجرا و از کدام صفحه‌ها تصویر بفرستید. فعلاً تست فروش، تعمیر یا حذف واقعی
نمی‌خواهم.

گزارش کامل و مرحله‌ای انگلیسی در [VALIDATION.md](VALIDATION.md) و ترتیب کار در
[ROADMAP.md](ROADMAP.md) است. این نسخه را برای استفادهٔ عادی نصب نکنید.
