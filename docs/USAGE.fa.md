# راهنمای کوتاه استفاده

این راهنما برای نسخهٔ فعلی افزونهٔ Dejunk-WotLK است. همهٔ فرمان‌های این صفحه
فقط تنظیمات را تغییر می‌دهند یا گزارش می‌سازند. فروش، حذف و تعمیر واقعی در این
نسخه به بازی وصل نیست.

## شروع سریع

1. افزونه را از ZIP در `Interface/AddOns/Dejunk-WotLK` نصب کنید؛ پوشهٔ اصلی
   `WTF` را دست‌کاری نکنید.
2. در بازی `/reload` بزنید و سپس `/djw status` را اجرا کنید. وضعیت باید `READY`
   باشد.
3. `/djw config` پنجرهٔ تنظیمات را باز می‌کند. برای بررسی کیف، از پیش‌نمایش
   `SELL` یا `DESTROY` استفاده کنید؛ این گزارش فقط‌خواندنی است.

## خواندن گزارش پیش‌نمایش

- `KEEP`: طبق تنظیم فعلی نگه داشته می‌شود.
- `JUNK`: فقط در شبیه‌سازی واجد شرایط فروش یا حذف شناخته شده است؛ هیچ کاری روی
  آیتم انجام نمی‌شود.
- `UNKNOWN`: دادهٔ لازم در دسترس نیست. افزونه مورد را امن نگه می‌دارد.
- خط پایانی `Eligible`, `Keep`, `Unknown` تعداد هر دسته را نشان می‌دهد.

اگر یک قانون آزمایشی باعث `JUNK` شدن موردی شده، ابتدا قوانین را ببینید:

```text
/djw rules list
```

هر قانون آزمایشی ناخواسته را با شناسهٔ خودش پاک کنید، برای نمونه:

```text
/djw rules remove test1
```

سپس پیش‌نمایش را دوباره اجرا کنید. پاک‌کردن قانون فقط تنظیمات را عوض می‌کند.

## قانون چندشرطی

قالب دستور:

```text
/djw rules add <id> <SELL|DESTROY|BOTH> <JUNK|KEEP> <ALL|ANY> <field> <EQ|LT|GT> <number> [<field> <operator> <number> ...]
```

نمونه:

```text
/djw rules add demo BOTH KEEP ANY itemId EQ 6948 quality EQ 0
```

این قانون می‌گوید آیتم با شناسهٔ `6948` یا هر آیتم با کیفیت `0` را `KEEP` کن.
در `ANY` یکی از شرط‌ها کافی است؛ در `ALL` باید همهٔ شرط‌ها برقرار باشند. فیلدها
`itemId`، `quality`، `itemLevel`، `unitVendorPrice` و `count` هستند. شناسهٔ قانون
در همان پروفایل باید یکتا باشد.

## فهرست آیتم‌ها و پروفایل‌ها

از `/djw config` وارد صفحهٔ `Lists` شوید. چهار فهرست سراسری و پروفایل دیده
می‌شوند؛ Import ابتدا شناسه‌ها را برای بازبینی نشان می‌دهد و Export متن قابل
کپی می‌دهد. تنظیمات `global` برای همهٔ پروفایل‌ها مشترک‌اند.

برای مشاهدهٔ فرمان‌های موجود در بازی:

```text
/djw help
```

پیش‌نمایش را بعد از هر تغییری که روی نتیجه اثر می‌گذارد دوباره بازبینی کنید.
`UNKNOWN` به معنی دادهٔ نامشخص است، نه تأیید برای اقدام روی آیتم.
