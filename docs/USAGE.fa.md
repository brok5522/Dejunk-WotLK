# وضعیت نسخهٔ توسعه‌ای

این شاخه هنوز انتشار آماده نیست و جایگزین کامل Dejunk برای WoW 3.3.5a محسوب
نمی‌شود. هدف، انتقال رفتار و رابط خود Dejunk به APIهای نسخهٔ 3.3.5a است؛ قرار
نیست امکانات تازه یا رابط جایگزین به آن اضافه شود.

اسکرین‌شات‌های قبلی فقط پیش‌نمایش‌های خواندنی و چند پنجرهٔ توسعه‌ای را تأیید
می‌کنند. آن‌ها اثبات نمی‌کنند فروش، حذف، تعمیر، رابط اصلی یا سازگاری کامل با
کلاینت کار می‌کند. تا تکمیل پورت و اعلام آماده‌بودن انتشار، این نسخه را برای
استفادهٔ عادی نصب نکنید.

فهرست مرجع رفتار و صفحه‌هایی که باید منتقل شوند در
[نقشهٔ پورت](ROADMAP.md) است. نسخهٔ بالادستی مرجع، Dejunk 3.5.1 در commit
`04bafd5e411441ef5b51bb8ed10d208f2d7758f5` است.
