# نسخهٔ تست جامع Dejunk-WotLK 0.16.54-dev

هدف فقط WoW اصلی 3.3.5a، بیلد 12340 و Interface 30300 است.
این نسخه نامزد تست جامع است؛ تکمیل مو‌به‌مو و اجرای کلاینت هنوز تأیید نشده‌اند.

پنج صفحهٔ اصلی، فهرست‌ها، پروفایل‌ها، میانبرها، پنجره‌های Junk/Lootable، آیکن‌های
کیف و مینی‌مپ و دکمهٔ تاجر پیاده‌سازی شده‌اند. فروش، تعمیر، بازکردن آیتم و حذف
به آداپتور قدیمی بازی متصل‌اند؛ برخلاف متن راهنمای قدیمی، این کنترل‌ها صرفاً
پیش‌نمایش نیستند. آزمون‌های توسعه فقط با API ساختگی و بدون موجودی واقعی اجرا شده‌اند.

[راهنمای مرحله‌به‌مرحلهٔ تست همین نسخه](CLIENT-TEST-0.16.54.fa.md) شامل نصب،
نتیجهٔ مورد انتظار هر بخش و قالب گزارش خطا است. ابتدا UI و ذخیره‌سازی را تست کنید؛
عملیات واقعی را فقط با آیتم کم‌ارزش انجام دهید. حذف واقعی در برنامهٔ تست نیست؛
برای دکمه‌های حذف، تأییدیه را بررسی و Cancel کنید.

[گزارش اعتبارسنجی](VALIDATION.md) و [اختلاف‌های باقی‌مانده](PARITY.md) را ببینید.
