# User-provided client evidence 04: Phase 2 persistence

Source: owner screenshots from original WoW 3.3.5a, build 12340, Interface 30300,
locale enUS. The owner reports taking a backup of the account WTF folder,
installing the Phase 2 ZIP, and running the commands in the Persian guide.

Observed sequence and results:
- `/djw status` reported READY / SUPPORTED_READ_ONLY.
- `/djw profile list` initially reported active `Default (default)`.
- `/djw profile create Test` reported `Created profile-1`; listing then showed
  `Test (profile-1)` active beside `Default`.
- `/djw lists add global inclusions 6948` reported `List updated`; showing the
  list displayed `6948`.
- After `/reload`, profile listing still showed active `Test (profile-1)` and
  global inclusions still showed `6948`.

This verifies original-client startup with the SavedVariables declaration,
profile creation/activation, global list editing and persistence through reload
for the reported setup. It is user-provided evidence; installed source commit and
client modification status are not independently captured. No item inventory
operation is shown or inferred. The global list is only settings data in Phase 2;
it does not classify or sell item 6948.
